METHODOLOGY

How implied value is computed

One function scores every protocol. No name is special-cased and no row is hand-picked. The model reads only the snapshot's own figures: TVL, seven-day TVL growth, and the time since the protocol was first listed — the best record of how long it has run with no token.

Comparables

Each category's multiple is the median market-cap-to-TVL ratio of the live-token protocols in that category — the market's own pricing of comparable protocols that already trade. A category with no live comparables falls back to the board-wide median. The detail panel shows the category's median multiple, how many live protocols it rests on, and the three largest live comparables with their own multiples.

What “no token” means

“Records no token” means the snapshot's DefiLlama record carries no market cap, no CoinGecko id and no symbol for the protocol. That record is not proof: a protocol on the board may still have a token its record does not carry. This radar never claims a protocol has no token — only that its record shows none.

Watchlist vs early

The watchlist is the floor: every protocol with at least of TVL that records no token. The early radar adds the pre-token protocols below that floor, ranked by TVL. The floor is never the whole board — the early rows are the radar's reason to exist.

Farm plans

Each protocol's six steps are concrete actions with what they cost and how long they take — capital, gas, hold time — derived from the protocol's category, chains, TVL and age. Nothing here is financial advice, and an implied value is an estimate of what a token would be worth if the protocol's record stayed as it is. It does not predict whether or when a token is issued.

How to verify this entry

Coverage: the board carries the full 40-protocol watchlist — see “Watchlist covered” in the totals above — plus the 186 early rows below the floor. Model: implied value is the function impliedValue in lib/model.ts — TVL × category multiple (median live mcap/TVL) × growth × maturity × breadth — reading only the snapshot’s own figures; no protocol name is special-cased anywhere in the scoring. Farm plans: each row’s six steps are derived from that row’s category, chains, TVL and age by the same derivation for every row. Reproduce it: run main.ts against the snapshot and compare board.json and data.js; the detail panel recomputes every row’s implied value from its own factors and flags any mismatch.
